Pin LiPo & BMS — Quản Lý Nguồn Di Động

Thiết kế hệ thống nguồn pin cho dự án nhúng — từ chọn pin đúng loại đến bảo vệ quá tải, sạc và đo mức pin.

⏱ Lý thuyết: ~35 phút🔬 Thực hành: 45 phút
🎯 Mục tiêu bài học
  • Hiểu đặc tính pin Li-ion/LiPo — điện áp 3,7V nominal, 4,2V đầy, 3,0V cắt
  • Quy ước dung lượng: mAh, C-rate — sạc 1C, xả tối đa
  • BMS (Battery Management System) — bảo vệ quá sạc, quá xả, ngắn mạch
  • Mạch sạc TP4056 — sạc 1A qua micro-USB, tích hợp BMS
  • Đo điện áp pin bằng ADC — tính phần trăm còn lại
  • Mạch nguồn tích hợp: pin LiPo + TP4056 + Boost 5V → ESP32
  • Ước tính thời gian pin từ dung lượng và dòng tiêu thụ
  • An toàn khi làm việc với pin Li-ion — không sạc pin bị phồng

1. Đặc tính pin Li-ion / LiPo

Thông sốGiá trịGhi chú
Điện áp tế bào (nominal)3,7VGiá trị trung bình khi xả
Điện áp đầy (full charge)4,20VKhông được vượt quá → hỏng pin, nguy hiểm
Điện áp cắt nguy hiểm3,0V (3,2V an toàn)Xả dưới 3V → hỏng pin không phục hồi
Xả hoàn toàn an toàn3,2–3,4VCắt nguồn tại đây để bảo vệ pin
Dòng sạc tiêu chuẩn0,5C–1C1C = sạc với I bằng dung lượng (mAh)
Thời gian sống = Dung lượng (mAh) / Dòng tiêu thụ (mA)
Ví dụ: Pin 2000mAh, dòng trung bình 80mA → T = 2000/80 = 25 giờ Thực tế × 0,8 (hiệu suất converter, nhiệt độ) → ~20 giờ thực

2. BMS và TP4056 — Sạc và bảo vệ pin

Module TP4056 + BMS tích hợp (module xanh/đỏ): micro-USB 5V ──→ [TP4056 CC/CV Charger] ──→ BAT+ / BAT− │ tích hợp BMS ↓ B+ ──[BMS]─── OUT+ ──→ Mạch tải (Boost, Vi điều khiển) B− ──[BMS]─── OUT− ──→ GND BMS bảo vệ: - Over-charge: V_bat > 4.25V → cắt sạc - Over-discharge: V_bat < 2.9V → cắt tải - Over-current: I > 3A → cắt (tùy module) - Short circuit: cắt tức thì Chú ý: module TP4056 đơn (không BMS) CHỈ sạc, không bảo vệ quá xả → cần module có BMS riêng!
// Đọc điện áp pin LiPo bằng ADC — ESP32
// Pin nối qua voltage divider: 100kΩ / 100kΩ → ADC pin (tỷ lệ 1:2)
// V_adc = V_bat / 2 → V_bat = V_adc × 2

const int BAT_PIN = 34;  // ESP32 ADC1 pin
const float V_FULL  = 4.20;
const float V_EMPTY = 3.20;

float readBatteryVoltage() {
  int raw = analogRead(BAT_PIN);
  float v_adc = (float)raw / 4095.0 * 3.3;  // ESP32 12-bit ADC
  return v_adc * 2.0;  // voltage divider ×2
}

int getBatteryPercent(float v) {
  if (v >= V_FULL)  return 100;
  if (v <= V_EMPTY) return 0;
  return (int)((v - V_EMPTY) / (V_FULL - V_EMPTY) * 100);
}

void loop() {
  float voltage = readBatteryVoltage();
  int percent = getBatteryPercent(voltage);
  Serial.printf("Pin: %.2fV (%d%%)\n", voltage, percent);
  if (percent < 10) Serial.println("CANH BAO: Pin sap het!");
  delay(5000);
}
🔥 An toàn pin LiPo — nghiêm túc tuân thủ
  • KHÔNG sạc pin bị phồng (swollen) — nguy cơ bốc cháy
  • KHÔNG để pin tiếp xúc nước hoặc kim loại sharp
  • KHÔNG xả pin dưới 3,0V — hỏng pin không thể phục hồi
  • Luôn dùng mạch BMS khi dùng trong dự án
  • Khi sạc: để trên bề mặt không cháy, không để qua đêm không ai trông

Thiết kế voltage divider để đo pin 4,2V max bằng ADC ESP32 (V_max_ADC=3,3V). Tỷ lệ và giá trị R cụ thể?

1: I_tổng = 240 + 300×2 = 840mA. T = 3000mAh / 840mA × 0,85 (hiệu quả Boost 5V) = 3,57 giờ × 0,85 = ~3 giờ thực tế. Để kéo dài: dùng Deep Sleep khi robot dừng, giảm PWM motor.

2: V_out/V_in = R2/(R1+R2) = 3,3/4,2 = 0,786. R2/(R1+R2) = 0,786 → R1/R2 = (1-0,786)/0,786 = 0,272. Chọn R2=100kΩ → R1=27,2kΩ → chọn 27kΩ. Kiểm tra: V_out = 4,2 × 100/(100+27) = 4,2 × 0,787 = 3,305V ≈ 3,3V ✓. Điện áp chia này <3,3V VCC → an toàn cho ADC ESP32.
