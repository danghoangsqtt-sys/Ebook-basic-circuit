Đồ Án — PCB Layout & Assembly

Chuyển từ breadboard prototype sang PCB chuyên nghiệp — layout chuẩn, hàn và power-on test lần đầu.

💻 KiCad PCB: 120 phút🔬 Assembly & Test: 90 phút
🎯 Mục tiêu bài học
  • Áp dụng quy tắc layout nâng cao cho đồ án thực tế
  • Phân chia vùng power và signal — tránh crosstalk
  • Test point — thêm test pad để debug dễ hơn
  • Via stitching cho ground plane — giảm EMI
  • Xuất Gerber và gửi sản xuất (JLCPCB, PCBWay — 5–10 ngày)
  • Assembly trên prototype PCB — hàn theo thứ tự IC trước
  • Quy trình power-on lần đầu — current limited PSU
  • Functional test theo test plan từ SRS

2. Test Point — Debug Professional

Thêm Test Point (TP) trong KiCad: Add → Add Footprint → tìm "TestPoint" Đặt tại các node quan trọng: Board: [TP_VCC3V3] [TP_GND] [TP_SDA] [TP_SCL] [TP_UART_TX] [TP_UART_RX] [TP_ADC_BAT] Khi debug: - Đặt GND clip vào TP_GND - Probe oscilloscope vào TP_SDA → xem I2C waveform - Probe multimeter vào TP_VCC3V3 → kiểm tra nguồn ổn định

3. Assembly Checklist — Hàn theo thứ tự

🔧 Thứ tự assembly đúng chuẩn

  1. Kiểm tra PCB lần cuối: Đúng orientation (mặt trước/sau), kiểm tra Gerber viewer, tất cả text đọc được.

  2. Hàn theo thứ tự: Thấp → Cao. Điện trở và tụ SMD nhỏ trước → IC SMD → Connector → Linh kiện THT → Header pin.

  3. Visual inspection: Kính lúp — kiểm tra từng mối hàn. Đặc biệt IC chân nhỏ.

  4. Continuity test: GND↔GND liên thông. GND↔VCC >10kΩ (không short).

  5. Current-limited power-on: Set I_limit = 100mA. Cấp nguồn. Xem I <50mA ở trạng thái idle. Không có linh kiện nóng bất thường.

  6. Functional test: Nạp firmware → Serial debug → test từng tính năng theo SRS.

Bài tập
📝 Bài tập Bài 46
1
Hoàn thiện PCB đồ án: DRC pass, thêm test points tại VCC/GND/SDA/SCL, via stitching, xuất Gerber.
2
Làm prototype trên PCB prototype pad (hoặc đặt in JLCPCB). Hàn theo thứ tự assembly chuẩn. Ghi lại I_idle sau power-on.

Sau power-on test, I_idle điển hình: ESP32 (WiFi off) ≈ 30–80mA, thêm OLED ≈ 10–20mA, BME280 ≈ 1mA. Tổng I_idle ≈ 50–100mA là bình thường. Nếu I_idle >500mA: có short circuit hoặc linh kiện lắp ngược cực (LED, diode, tụ điện phân). Nếu <10mA: MCU chưa chạy được (VCC không đủ, quartz hỏng, nạp firmware chưa thành công).
