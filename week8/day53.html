BLE — Bluetooth Low Energy Với ESP32

Không cần WiFi, không cần router — BLE truyền dữ liệu thẳng đến điện thoại với năng lượng cực thấp. Lý tưởng cho thiết bị đeo tay và IoT.

⏱ Lý thuyết: ~30 phút💻 Thực hành: 60 phút
🎯 Mục tiêu bài học
  • Phân biệt Classic Bluetooth vs BLE — dải tần, tốc độ, tiêu thụ
  • GATT (Generic Attribute Profile) — Service, Characteristic, UUID
  • ESP32 làm BLE Server — advertise và kết nối điện thoại
  • Truyền dữ liệu: Notify (server→phone) và Write (phone→server)
  • Kiểm tra BLE bằng app "nRF Connect" trên điện thoại
  • BLE UART service — thay thế Serial qua Bluetooth
  • Power consumption BLE vs WiFi — khi nào dùng BLE

1. BLE Architecture — GATT Model

BLE GATT Hierarchy: Device (ESP32 BLE Server) └── Service UUID: 4fafc201-... (Temperature Monitoring) ├── Characteristic UUID: beb5483e-... (Temperature) │ ├── Properties: READ + NOTIFY │ └── Value: "25.3" (float as string) └── Characteristic UUID: cba1d466-... (LED Control) ├── Properties: WRITE └── Value: "1" (ON) / "0" (OFF) Điện thoại (BLE Client) └── nRF Connect app → Scan → Connect → Read/Write Characteristic

2. ESP32 BLE Server — Code

// ESP32 BLE Server — gửi nhiệt độ lên điện thoại
#include <BLEDevice.h>
#include <BLEServer.h>
#include <BLEUtils.h>
#include <BLE2902.h>

#define SERVICE_UUID        "4fafc201-1fb5-459e-8fcc-c5c9c331914b"
#define TEMP_CHAR_UUID      "beb5483e-36e1-4688-b7f5-ea07361b26a8"

BLECharacteristic* tempChar;
bool deviceConnected = false;

class MyServerCallbacks: public BLEServerCallbacks {
  void onConnect(BLEServer* s)    { deviceConnected = true; }
  void onDisconnect(BLEServer* s) { deviceConnected = false; s->startAdvertising(); }
};

void setup() {
  BLEDevice::init("ESP32-WeatherStation");
  BLEServer* server = BLEDevice::createServer();
  server->setCallbacks(new MyServerCallbacks());
  
  BLEService* service = server->createService(SERVICE_UUID);
  
  tempChar = service->createCharacteristic(
    TEMP_CHAR_UUID,
    BLECharacteristic::PROPERTY_READ | BLECharacteristic::PROPERTY_NOTIFY
  );
  tempChar->addDescriptor(new BLE2902());  // Enable notifications
  
  service->start();
  server->getAdvertising()->start();
  Serial.println("BLE Server started. Scan with nRF Connect!");
}

void loop() {
  if (deviceConnected) {
    float temp = bme.readTemperature();
    String tempStr = String(temp, 1);  // "25.3"
    tempChar->setValue(tempStr.c_str());
    tempChar->notify();  // Push to phone
    delay(2000);
  }
}

Thêm characteristic WRITE: điện thoại gửi "1"/"0" → bật/tắt LED trên ESP32. Xác nhận hoạt động 2 chiều.

Tạo LED Characteristic với PROPERTY_WRITE. Tạo callback class kế thừa BLECharacteristicCallbacks, override onWrite(): void onWrite(BLECharacteristic* pChar) { String val = String(pChar->getValue().c_str()); if(val=="1") digitalWrite(LED,HIGH); else digitalWrite(LED,LOW); }. Attach: ledChar->setCallbacks(new LedCallback());. Trong nRF Connect: chọn characteristic → write → nhập "31" (hex cho '1') hoặc dùng text input.
