ADC & DAC — Chuyển Đổi Tín Hiệu Analog ↔ Số

Cầu nối giữa thế giới analog (nhiệt độ, âm thanh, ánh sáng) và vi điều khiển số — nền tảng của mọi hệ thống đo lường.

⏱ Đọc: ~45 phút🔬 Thực hành: 45 phút
🎯 Mục tiêu bài học
  • Hiểu ADC là gì — chuyển điện áp analog thành số nguyên N-bit
  • Hiểu độ phân giải: ADC 10-bit vs 12-bit vs 16-bit
  • Tính LSB voltage và sai số quantization
  • Hiểu Sampling Rate và định lý Nyquist — aliasing
  • Hiểu AREF và tại sao quan trọng với độ chính xác ADC
  • Đọc cảm biến analog (biến trở, LDR, NTC) với Arduino/ESP32
  • Hiểu DAC là gì — ESP32 có 2 DAC 8-bit
  • Dùng DAC để tạo sóng sine đơn giản và âm thanh cơ bản

1. ADC — Chuyển đổi Analog → Digital

ADC (Analog-to-Digital Converter) đọc điện áp analog (ví dụ 0–3,3V) và chuyển thành số nguyên. Độ chính xác phụ thuộc vào số bit:

V_input = (ADC_value / (2^N – 1)) × V_ref
N = Số bit ADC (10, 12, 16...) ADC_value = Giá trị đọc được (0 → 2^N – 1) V_ref = Điện áp tham chiếu (thường = VCC) LSB = V_ref / (2^N – 1) = điện áp nhỏ nhất phân giải được

1.1 AREF — Điện áp tham chiếu ADC

⚠️ ESP32 ADC — hạn chế quan trọng cần biết

ADC của ESP32 có một số hạn chế thực tế: (1) Không đọc chính xác ở đầu range (0–0,1V và 3,1–3,3V) — đặc tính phi tuyến; (2) ADC2 không dùng được khi WiFi đang hoạt động; (3) Cần calibration để đạt độ chính xác ±50mV. Với ứng dụng đo lường chính xác, dùng ADC ngoài (ADS1115) qua I2C.

2. Sampling Rate & Định lý Nyquist

ADC không đọc liên tục — nó lấy mẫu (sample) tín hiệu tại các thời điểm rời rạc. Tần số lấy mẫu f_s phải thỏa mãn:

f_s ≥ 2 × f_signal_max  (Định lý Nyquist-Shannon)
Nếu f_s < 2 × f_signal: xảy ra "aliasing" — tín hiệu bị đọc sai tần số Ví dụ: tín hiệu âm thanh 20kHz → cần f_s ≥ 40kHz (CD audio: 44,1kHz) Nhiệt độ thay đổi chậm (Hz) → Arduino analogRead() 10kHz là đủ

3. Thực hành ADC — Đọc biến trở và NTC

// ADC đọc biến trở + tính điện áp thực
const int PIN_POT = A0;
const float V_REF = 5.0;    // Arduino Uno AREF = VCC = 5V
const int ADC_BITS = 10;    // 10-bit ADC

void setup() { Serial.begin(115200); }

void loop() {
  int raw = analogRead(PIN_POT);           // 0–1023
  float voltage = (float)raw / (pow(2, ADC_BITS) - 1) * V_REF;
  
  Serial.print("Raw: "); Serial.print(raw);
  Serial.print("  Voltage: "); Serial.print(voltage, 3);
  Serial.println(" V");
  delay(100);
}

4. DAC — Chuyển đổi Digital → Analog

DAC (Digital-to-Analog Converter) là quá trình ngược lại ADC: chuyển số nguyên thành điện áp analog. ESP32 có 2 DAC 8-bit (GPIO 25 và 26), cho phép tạo điện áp từ 0 đến 3,3V với độ phân giải 256 bước (~13mV/bước).

// ESP32 DAC — tạo sóng sine đơn giản
#include <math.h>

const int DAC_PIN = 25;  // GPIO 25 = DAC1
const int SAMPLES = 100;

void setup() {}

void loop() {
  for (int i = 0; i < SAMPLES; i++) {
    // Sine từ 0→255 (0→3.3V)
    float angle = 2.0 * PI * i / SAMPLES;
    int dac_val = (int)((sin(angle) + 1.0) * 127.5);  // 0–255
    dacWrite(DAC_PIN, dac_val);
    delayMicroseconds(100);  // f ≈ 1/(100×100µs) = 100Hz
  }
}
