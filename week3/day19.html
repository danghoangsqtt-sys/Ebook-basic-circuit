PWM — Điều Rộng Xung & Điều Khiển Tốc Độ

Kỹ thuật mô phỏng điện áp analog bằng xung số — điều khiển độ sáng LED, tốc độ motor và truyền thông servo.

⏱ Đọc: ~35 phút🔬 Thực hành: 40 phút

  • Hiểu Duty Cycle (%) và tần số (Hz) — hai tham số quan trọng nhất

  • Hiểu tại sao cần tần số PWM phù hợp với motor (không nghe tiếng kêu)
  • Mô phỏng điện áp analog bằng PWM + RC filter

1. PWM — Điều Rộng Xung (Pulse Width Modulation)

PWM là kỹ thuật thay đổi độ rộng (thời gian) của xung điện trong một chu kỳ cố định để điều khiển giá trị điện áp trung bình đến tải. Thay vì thay đổi điện áp một cách liên tục (như DAC analog), PWM chuyển đổi nhanh giữa 0V và V_max — tải "cảm nhận" điện áp trung bình tương ứng.

PWM — 3 ví dụ duty cycle khác nhau: Cùng chu kỳ T = 8 ô thời gian, █ là HIGH và · là LOW: Duty 25%: ██······ | ██······ V_avg = 1,25V (mức 5V) Duty 50%: ████···· | ████···· V_avg = 2,50V Duty 75%: ██████·· | ██████·· V_avg = 3,75V D = T_on / T × 100%. Độ sáng LED thường tăng theo duty; tốc độ motor phụ thuộc tải, đặc tính motor và mạch điều khiển, nên duty 50% không mặc định bằng nửa tốc độ.
V_avg = D × V_high
D = Duty Cycle (0.0 → 1.0, hay 0% → 100%) V_high = Điện áp mức cao (VCC) f_PWM = 1/T = Tần số PWM (Hz)

2. Chọn tần số PWM phù hợp

Ứng dụngTần số PWM khuyến nghịLý do
LED dimming500Hz–10kHzTrên 50Hz: mắt không nhận ra nhấp nháy (flicker-free)
Motor DC nhỏ1kHz–20kHzTrên 20kHz: motor không kêu (ngưỡng nghe của người)
Servo RC50Hz (chu kỳ 20ms)Tiêu chuẩn servo: T_on = 1ms–2ms điều khiển góc
DC-DC Converter100kHz–2MHzTần số cao → cuộn cảm và tụ nhỏ hơn
Audio class D amplifier200kHz–500kHzTrên 10× tần số âm thanh max (20kHz)
📌 PWM trên ESP32 và Arduino
  • ESP32: LEDC peripheral — 16 kênh, tần số từ 1Hz đến 40MHz, độ phân giải 1–16 bit. Dùng ledcWrite(channel, duty)
  • Arduino Uno/Nano: analogWrite(pin, 0–255) — tần số 490Hz (pin 3,9,10,11) hoặc 980Hz (pin 5,6). Phân giải 8-bit.
  • Arduino Mega: Tương tự nhưng có thêm pin PWM trên Timer 3,4,5

3. PWM → Điện áp Analog: RC Low-Pass Filter

Nếu bạn cần điện áp analog thực sự (ví dụ: DAC cho âm thanh, điện áp tham chiếu biến đổi), có thể dùng RC Low-Pass Filter sau ngõ ra PWM để lọc bỏ thành phần tần số cao, chỉ giữ lại giá trị trung bình DC:

PWM → Analog qua RC filter: GPIO_PWM ──[R=10kΩ]──┬── V_analog_out │ [C=100nF] │ GND f_PWM = 10kHz → f_c_filter = 1/(2π×10k×100n) = 159Hz → f_PWM (10kHz) >> f_c (159Hz) → filter lọc gần hết ripple → V_out ≈ D × 3,3V (rất trơn)

4. Thực hành: Dimmer LED và điều khiển tốc độ motor

🔬 Thực hành A: Dimmer LED bằng Arduino analogWrite
// Dimmer LED — Arduino
const int LED_PIN = 9; // Pin PWM
void setup() { pinMode(LED_PIN, OUTPUT); }
void loop() {
  // Tăng dần sáng
  for (int d = 0; d <= 255; d++) {
    analogWrite(LED_PIN, d);
    delay(10);
  }
  // Giảm dần tối
  for (int d = 255; d >= 0; d--) {
    analogWrite(LED_PIN, d);
    delay(10);
  }
}

  1. Nối LED + R(220Ω) vào pin 9 Arduino. Upload code trên. Quan sát LED breathing.

  2. Đo điện áp trung bình tại chân PWM so với GND khi cố định analogWrite(LED_PIN, 128): kỳ vọng gần 2,5V. Điện áp đo trực tiếp hai đầu LED không bằng điện áp trung bình chân PWM vì LED là tải phi tuyến.

  3. Thay pin 9 bằng pin 5 hoặc 6 (490Hz→980Hz): có thấy sự khác biệt không?

🔬 Thực hành B: Điều khiển tốc độ motor DC qua MOSFET

  1. Lắp mạch IRLZ44N switch (như Bài 18) nhưng thêm GPIO PWM vào Gate qua R_G=100Ω.

  2. Với Arduino Uno, dùng analogWrite(PWM_PIN, 64/128/255) tương ứng khoảng 25%/50%/100% duty. Đo tốc độ thực tế vì tốc độ motor không tỉ lệ tuyến tính chắc chắn với duty.

  3. Quan sát tốc độ motor thay đổi. Nghe âm thanh: ở 490Hz motor thường phát tiếng kêu.

  4. Nếu dùng Arduino-ESP32 core 3.x: thử ledcAttach(PWM_PIN, 20000, 8) rồi ledcWrite(PWM_PIN, 128) cho duty 50% ở 20kHz. So âm thanh motor với tần số thấp và kiểm tra giới hạn driver.
