2. Mini Project Tuần 3: Mạch Báo Nhiệt Tự Động

📋 Yêu cầu kỹ thuật
  • Cảm biến: NTC Thermistor 10kΩ — điện trở giảm khi nhiệt độ tăng
  • Mạch phân áp: NTC + R_ref = 10kΩ → tạo V_sensor thay đổi theo nhiệt độ
  • So sánh ngưỡng: Op-Amp LM358 Comparator — V_ref từ biến trở
  • Khi nhiệt > ngưỡng: comparator output HIGH → BJT BC337 ON → Relay đóng → Quạt bật
  • LED đỏ: báo trạng thái HOT (relay ON)
  • LED xanh: báo trạng thái NORMAL (relay OFF)
  • Nguồn: 5V cho cảm biến và logic; 12V cho quạt (hoặc dùng relay để điều khiển tải tùy ý)

2.1 Nguyên lý NTC Thermistor

NTC (Negative Temperature Coefficient) thermistor là điện trở đặc biệt có điện trở giảm khi nhiệt độ tăng. NTC 10kΩ = điện trở 10kΩ ở 25°C. Khi nhiệt độ tăng lên 50°C, điện trở giảm xuống khoảng 3–4kΩ.

Mạch phân áp NTC + R_ref: VCC(3.3V) ──[R_ref=10kΩ]──┬── V_sensor → IN(+) Op-Amp │ [NTC 10kΩ] ← nhiệt độ cao → R_NTC nhỏ → V_sensor nhỏ │ GND Khi nhiệt độ THẤP: R_NTC lớn → V_sensor lớn (gần VCC) Khi nhiệt độ CAO: R_NTC nhỏ → V_sensor nhỏ (gần GND) → Comparator: IN(–) = V_ref (biến trở). Khi V_sensor < V_ref: output HIGH = HOT!

2.2 Sơ đồ khối hệ thống

Hệ thống Báo Nhiệt Tự Động: [NTC Thermistor] ─┐ [R_ref = 10kΩ] ─┤→ V_sensor → [Op-Amp Comparator] → HIGH/LOW [Pot = V_ref] ───┘ (LM358) │ │ HIGH khi HOT ↓ [LED đỏ + R470Ω] → "CẢNH BÁO NHIỆT" │ [BC337 NPN switch] [R_B = 1kΩ] │ [Relay 5V + Freewheeling diode] │ [LED xanh chỉ thị relay ON] hoặc [Quạt DC / Tải]

2.4 Quy trình lắp mạch

🔌 Lắp mạch theo thứ tự an toàn

  1. Cấp nguồn: Lắp AMS1117-3.3 hoặc dùng nguồn 5V, GND.

  2. Mạch phân áp: 3,3V → R_ref(10kΩ) → NTC → GND. Đo V_sensor ở điểm giữa (kỳ vọng ~1,65V ở nhiệt phòng).

  3. V_ref: 3,3V → Biến trở 10kΩ → GND. Giữa biến trở nối vào IN(–) LM358. Chỉnh biến trở sao cho V_ref ≈ 1,3V (ngưỡng ~35°C).

  4. LM358 Comparator: V_sensor → IN(+), V_ref → IN(–). 100nF từ VCC(pin 8) → GND(pin 4) sát IC. Đo V_out (pin 1).

  5. LED đỏ: V_out (pin 1) → R(470Ω) → LED đỏ → GND. LED sáng = nhiệt cao.

  6. BJT + Relay: V_out → R_B(1kΩ) → Base BC337. Collector → Relay cuộn (+). Emitter → GND. Diode freewheeling. Relay (+) từ 5V.

  7. Test: Dùng ngón tay hoặc hà hơi ấm vào NTC. V_sensor giảm → V_sensor < V_ref → Comparator output LOW → LED tắt, relay nhả. Tiếp tục hà hơi đến khi ngược lại.

  8. Điều chỉnh ngưỡng: Chỉnh biến trở V_ref để hệ thống kích hoạt ở nhiệt độ mong muốn.
