2. Mini Project Tuần 5: PCB Buck Converter 12V→5V/1A

📋 Thông số kỹ thuật
  • IC: LM2596S-5.0 (TO-263, fixed 5V output) — hoặc LM2596S-ADJ (điều chỉnh)
  • V_in: 8–40V (terminal screw 5.08mm)
  • V_out: 5V ±2%, I_max = 1A
  • Cuộn cảm: L = 68µH (SMD 8×8mm hoặc THT có chân)
  • Diode freewheeling: SS14 Schottky SMA, 1A/40V
  • Tụ đầu vào: 100µF/50V electrolytic + 100nF ceramic
  • Tụ đầu ra: 220µF/16V ESR thấp + 100nF ceramic
  • Output indicator LED: LED xanh + R=1kΩ/0805
  • Connector đầu ra: 2-pin JST 2.54mm hoặc screw terminal

2.1 Schematic LM2596S-5.0

Mạch LM2596S-5V chuẩn từ datasheet: VIN(+) ─────┬──────── [L=68µH] ─────┬── VOUT(+) │ │ [C_in 100µF] [C_out 220µF] [100nF parallel] [100nF parallel] │ [SS14 Schottky] │ VIN(−) ─────┴──── Cathode ←── Anode ─┴── VOUT(−) = GND LM2596S chân: [1=OUT 2=VIN 3=GND 4=FB 5=ON/OFF] (TO-263) Fixed 5V: FB (pin 4) nối thẳng VOUT — không cần R_fb ON/OFF (pin 5): nối GND để luôn ON

2.2 Quy trình thiết kế PCB trong KiCad

💻 Thiết kế PCB Buck Converter từng bước

  1. Vẽ schematic đầy đủ theo sơ đồ trên. Chú ý symbol LM2596S trong KiCad library (Regulator_Switching).

  2. Assign footprint: LM2596 → TO-263-5, SS14 → D_SMA, L → IND SMD 7×7, C_out 220µF → CP_Radial_D8mm.

  3. PCB Layout: VIN connector → C_in → LM2596 → L → C_out → VOUT connector. Layout phải compact, loop VIN→IC→L→C_out→GND phải ngắn nhất có thể.

  4. Track width: VIN, VOUT, GND power = 2mm (1A). Tín hiệu ON/OFF = 0,3mm.

  5. Ground plane B.Cu. Thermal relief cho IC TO-263 trên GND pad.

  6. Thêm silk screen: "IN+", "IN−", "OUT+", "OUT−". Version, date.

  7. DRC → 0 errors → Xuất Gerber + Drill files → Tải lên JLCPCB/PCBWay để báo giá (5 PCB ~$2–5).

2.3 Điểm quan trọng về layout Buck Converter

⚡ Layout Buck Converter — 3 lỗi phổ biến nhất
  1. Loop nhiễu lớn: Vòng lặp VIN → IC switch → D_freewheeling → GND phải cực nhỏ. Loop lớn = ăng-ten EMI → nhiễu xuyên sang mạch khác.
  2. Cạnh switching node (SW) dài: Nút SW (nối IC output, diode anode, cuộn cảm) là nguồn EMI chính. Track phải cực ngắn và không gần tín hiệu analog nhạy cảm.
  3. Tụ đầu vào xa IC: C_in phải sát chân VIN của IC — loại bỏ spike dòng khi MOSFET bật.
