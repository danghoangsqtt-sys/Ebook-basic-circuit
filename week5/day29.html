Mô Phỏng Mạch — Falstad & LTSpice

Thiết kế và kiểm tra mạch điện trên máy tính trước khi làm thực tế — tiết kiệm linh kiện, phát hiện lỗi sớm.

⏱ Lý thuyết: ~25 phút💻 Thực hành phần mềm: 60 phút
🎯 Mục tiêu bài học
  • Biết mô phỏng là gì và tại sao quan trọng trong thiết kế điện tử
  • Sử dụng Falstad Circuit Simulator (web, miễn phí) cho mạch cơ bản
  • Mô phỏng mạch RC, BJT switch, Op-Amp trên Falstad
  • Cài và sử dụng LTSpice (miễn phí) cho mạch phức tạp hơn
  • Phân tích DC Operating Point — tìm V, I tại mọi nút
  • Phân tích Transient — xem dạng sóng theo thời gian
  • Phân tích AC — đáp ứng tần số của mạch filter
  • So sánh kết quả mô phỏng với đo kiểm thực tế — hiệu chỉnh

2. Falstad Circuit Simulator — Mô phỏng trực tuyến

Falstad (falstad.com/circuit) là trình mô phỏng mạch miễn phí chạy trên trình duyệt. Hiển thị dòng điện chạy như animation — rất trực quan để hiểu nguyên lý hoạt động.

💻 Thực hành A: Mô phỏng mạch RC trên Falstad

  1. Mở falstad.com/circuit. Xóa mạch mặc định (Edit → Clear All).

  2. Thêm: Voltage Source (Draw → Voltage Source) → đặt 5V DC. Thêm Resistor 10kΩ nối tiếp. Thêm Capacitor 10µF song song với đầu ra.

  3. Right-click lên Voltage Source → Edit → Waveform: Square Wave, 1Hz, Amplitude 5V.

  4. Right-click lên nút output → Add Scope → quan sát dạng sóng nạp/xả tụ. Xác nhận τ = RC = 10k × 10µF = 0,1s.

  5. Thay C = 1µF → quan sát τ nhỏ hơn 10×. So sánh với lý thuyết.

💻 Thực hành B: Mô phỏng BJT NPN switch trên Falstad

  1. Draw → Transistors → NPN Transistor. Đặt VCC=5V, R_C=1kΩ, LED load, R_B=10kΩ từ Base.

  2. Đặt V_Base = 0V → LED tắt. Đặt V_Base = 3,3V → LED sáng. Đọc I_C từ Scope.

  3. Right-click transistor → Edit → xem thông số hFE. Thay đổi hFE → xem V_CE thay đổi thế nào.

3. LTSpice — Mô phỏng mạch chuyên nghiệp

LTSpice do Analog Devices cung cấp miễn phí — là công cụ mô phỏng SPICE mạnh nhất miễn phí, dùng trong công nghiệp. Tải tại: analog.com/en/.../ltspice.

3.1 Ba loại phân tích quan trọng trong LTSpice

Phân tíchLệnhDùng đểVí dụ
DC Operating Point.opTìm điện áp, dòng tại mọi nút khi mạch DC ổn địnhKiểm tra Q-point BJT
Transient Analysis.tran 10msDạng sóng theo thời gian (step response, oscillation)Xem mạch RC nạp/xả
AC Analysis.ac dec 100 10Hz 1MHzĐáp ứng tần số — Bode plot (magnitude, phase)Đặc tính bộ lọc RC
💻 Thực hành C: Phân tích AC mạch RC Low-Pass Filter trong LTSpice

  1. Vẽ mạch: V1 (AC source, amplitude 1V) → R=10kΩ → C=100nF → GND. Đặt probe tại đầu ra C.

  2. Run → AC Analysis: .ac dec 100 10Hz 1MHz

  3. Xem Bode plot. Tại f_c = 159Hz (= 1/2π×10k×100n): magnitude phải = –3dB (≈ 0,707 × V_in).

  4. Thay C = 10nF → f_c dịch chuyển đến 1,59kHz. So sánh với công thức.

Mô phỏng mạch RC High-Pass Filter (R và C đổi chỗ) trên Falstad. f_c = ? khi R=22kΩ, C=47nF. Xác nhận bằng Bode plot.

3
Tại sao kết quả mô phỏng và thực tế thường khác nhau? Liệt kê 3 lý do chính.

1: HPF: R nối tiếp đầu ra, C nối đầu vào. f_c = 1/(2π×22000×0,000000047) = 1/0,00651 = 153,7Hz. Trên Bode plot: gain tăng với tần số, –3dB tại ~154Hz.

2: Đo biên độ V_out đỉnh-đỉnh / V_in đỉnh-đỉnh từ waveform. So sánh với tính toán: A_V_tính = –R_C/r_e. Kết quả mô phỏng thường gần với lý thuyết hơn thực tế.

3: (a) Mô hình SPICE không hoàn hảo: model transistor/op-amp giả định tham số lý tưởng, thực tế có sai số sản xuất ±20–50%; (b) Ký sinh (parasitics): điện trở đường dây, tụ ký sinh PCB, inductance — không có trong mô phỏng đơn giản; (c) Nhiệt độ và lão hóa: linh kiện thực thay đổi theo nhiệt độ và thời gian sử dụng.
